# Darkest Hour Mod — AI Instructions

## Project Overview

This is a modification for **Darkest Hour**, using the game's proprietary text-based scripting/configuration systems.

When working on this project, do not assume that conventional programming-language rules apply. Refer to the scripting language as "DHFScript". Do not assume that syntax or behavior from EU4, HOI3, HOI4, or other Paradox games applies to Darkest Hour.

## General Rules

* Treat the existing project files as the primary source of truth for syntax and conventions.
* Before making substantial changes, inspect existing examples of the same or similar functionality.
* Do not invent commands, triggers, effects, modifiers, parameters, or syntax merely because they would make sense conceptually.
* If you are uncertain whether a command or construct is supported by the Darkest Hour engine, say so rather than silently assuming that it is.
* Preserve the existing formatting and organization of files unless there is a specific reason to change them.
* Make the smallest changes necessary to accomplish the requested task.
* Do not modify executable files or otherwise require changes to the game's executable unless explicitly requested.
* Do not rewrite unrelated portions of files.
* When modifying an existing feature, first identify how the existing feature works and which files control it.
* Prefer existing working examples within this project over generic knowledge about Hearts of Iron II, Darkest Hour, or other Paradox games.
* All modified files MUST be saved in `Latin-1` (`cp1252`) encoding.


## Understanding the Project

Before implementing unfamiliar functionality:

1. Identify the relevant file or directory.
2. Find existing examples of similar functionality.
3. Consult the appropriate documentation in `docs/`.
4. Determine how the relevant syntax is actually used in this project.
5. Explain any important uncertainty before making a potentially risky change.

Do not assume that a command exists simply because a similarly named command exists in another Paradox game or another version of the engine.

## DH mod folder structure

- `map/Map_3/` - custom E3 map related files.
- `map/Map_3/Province.csv` - list of all provinces on the E3 map with ids and starting resource values.
- `map/Map_3/adj-defs.csv` - list of province connections that differ from ordinary adjacent provinces (rivers, canals, impassable, etc).
- `config/` - text and localization csv files. The engine will parse all 18 files with predefined names in this folder when looking for a reference key.
- `config/modtext.csv` - all new event-related text should go to here.
- `db/` - contains the main game databases and scripted game definitions.
- `db/events.txt` - list of event files in `db/events/` to load at scenario start.
- `db/leaders.txt` - list of leader files in `db/leaders/` to load at scenario start.
- `db/ministers.txt` - list of minister files in `db/ministers/` to load at scenario start.
- `db/teams.txt` - list of tech teams files in `db/tech/teams/` to load at scenario start.
- `db/country.csv` - contains the complete list of all available country TAGs and basic country info.
- `db/misc.txt` - main engine/gameplay constants and defines, use for reference only and do not modify.
- `db/tech/` - contains 9 files describing researchable technologies, their requirements and dependencies.
- `db/units/` - contains data on divisions and brigades, which are the main unit types in the game.
- `scenarios/` - contains starting scenario definitions and save games.
- `scenarios/E3Map.eug` - main scenario for this mod.
- `scenarios/1936/` - country definition files for the E3Map scenario. They are directly included in the scenario definition file at runtime when the scenario is loaded.
- `scenarios/save games/` - save files generated by the game at runtime. Save files follow a nearly identical format to the scenario definition and country definition files.
- `ai/` - AI configuration files used by the in-game AI to guide behavior.
- `ai/default.ai` - currently used as a generic baseline AI loaded for all new AI-controlled countries upon independence or at scenario start. Other AI files are typically loaded afterward to override specific behaviors in default.ai.
- `ai/nations/` - subfolder for ai files meant for specific countries in specific situations which are difficult to generalize.
- `gfx/` - graphics and interface assets.
- `gfx/events_pics` - event and decision pictures.
- `sfx/` - sound assets, generally should not be touched.

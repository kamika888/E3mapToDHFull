# `stem_debug.csv` Column Reference

Semicolon-delimited (`;`) debug telemetry dumped to `stem_debug.csv` in the Darkest Hour root directory upon saving (manual save or autosave) when `EnableEncirclementDefense = 1` in `db/mod_settings.ini` **and** `Extra debug logs` (line 9 of `settings.cfg`, runtime flag `byte ptr [0x00DC4B5E]`) is set to `1` or `2`.

| Column | Meaning |
|---|---|
| `CountryTag` | 3-letter tag of the evaluated AI country controlling the province (`UNK` if lookup fails). |
| `ProvID` | Numeric province ID (`1..8020`). |
| `ProvName` | Localized province name read from `[CProvince + 4]` (English name from `map/Map_3/province_names.csv` when running in English; `UNK` if null). |
| `Dist` | BFS hop distance (`0..65535`) from the nearest safe rear horizon / capital / depot (`0` = safe root). |
| `IsThreatened` | `1` if Pass 0 flagged the province as threatened (`+0x24000`), `0` otherwise. Set either when friendly defenders are losing badly in combat here (`0x004BEBE0` progress <= `0.40` or avg division org < `NeckCollapsingOrgThreshold`), or when an active hostile moving army's immediate next hop (`[army + 0x27E] == 1`, `[army + 0x232]` list head) targets an unguarded friendly province. |
| `F_Paths` | Max-flow count of vertex-disjoint safe escape paths from this province to safe roots, capped at `SalientNeckWidthThreshold` (`3`). Reaching `SalientNeckWidthThreshold` immediately marks the province safe (`SalientEvacuationQuota = 0.000`). |
| `F_Exp` | Count of extracted minimum-cut bottleneck vertices (`1 <= F_Paths < W`) that have `IS_LAND_EXPOSED` (`prov_flags` bit `0x08`: borders a war enemy / hostile army, or borders an `IsThreatened == 1` province). If `F_Exp == 0` and `IsThreatened == 0`, the **Natural Geography Gate** zeroes the quota. |
| `F_Crit` | Subset of `F_Exp` cut vertices that are already `IsThreatened == 1` or have individual bottleneck threat `T(v) >= 1.0`. |
| `CutProv1`, `CutProv2` | First two province IDs on the residual max-flow minimum cut separating the province from the safe rear (`0` if safe, `F_Paths == 0`, or fewer cut vertices exist). |
| `V_Ref` | Reference vertex ID (`v_ref`, stored at `g_pGraphTable + 0xC8000`) whose `FrStr`, `EnStr`, `InbStr`, and `MinOrg` are reported (worst exposed corridor vertex along contracted cuts if any, else `CutProv1`, else the province itself). |
| `EvacDestNeck` | Resolved evacuation destination neck province ID (`0` when not evacuating). |
| `FrStr` | Effective friendly non-retreating defensive strength at **reference vertex `v_ref`** (raw strength x `def_mult(v_ref)`, i.e., terrain defense bonus + `misc.txt` Land Fort Multiplier x fort level), so `FrStr + InbStr` equals the exact `FrEff` denominator used in `T_Neck`. |
| `EnStr` | Weighted enemy strength threatening `v_ref` (`en_eff_str_f32`): sum of `ActiveEnemyAttackWeight` for enemy divisions actively attacking or moving into `v_ref` (x `0.70` across a river/strait), plus `IdleEnemyPresenceWeight` x adjacent idle `raw_hostile_str` (x `0.70` across a river/strait), plus `ThreatenedNeighborStrWeight` propagated from adjacent `IsThreatened` friendly provinces via Pre-Pass B. |
| `InbStr` | Effective inbound friendly non-retreating strength currently marching into `v_ref` (`[army + 0x27E] == 1` and immediate next hop `[army + 0x232]` head == `v_ref`, excluding active STEM evacuations `[slot + 6] != 0`), scaled by `InboundFriendlyStrWeight` x `def_mult(v_ref)`, so `FrStr + InbStr` equals `FrEff` in `T_Neck`. |
| `MinOrg` | Province-wide weighted average defender organization (`0..254`, or `255` when not in defensive combat) across holding friendly divisions in `v_ref`. |
| `VP_IC_Val` | Strategic value of this province plus its friendly-controlled land neighbors: `sum(max(0, VP) + 0.5 * max(0, IC))`. |
| `D_Width` | Neck-width deficit in `[0.000, 1.000]`, `max(0, (W - (F_shelt + ExposedIntactPathCredit * F_intact_exp)) / W)`, scaled by `WidthDeficitWeight`, where `F_shelt = F_Paths - F_Exp` and `F_intact_exp = F_Exp - F_Crit` (`0.000` when gated safe; `1.000` when `F_Paths == 0`). |
| `T_Neck` | Bottleneck threat urgency clamped to `[NeckThreatMinFloor, NeckThreatMaxCap]` then scaled by `NeckThreatWeight`: worst cut vertex threat `T(v_max) * (1 + MultiExposedCutBonus * (F_Exp - 1))`, where `T(v)` compares `EnStr(v)` against `max(1.0, FrStr(v) + InbStr(v))`, ramping linearly from `0.0` at `NeckThreatMinRatio` to `1.0` at `NeckThreatRatio` -- or `NeckThreatMaxCap` when unguarded with `EnStr > 0.05` -- combined with `max` of low-org urgency against `NeckCollapsingOrgThreshold`. |
| `V_Ret` | Value-retention multiplier clamped to `[ValueRetentionMinFloor, 1.000]`: `max(ValueRetentionMinFloor, 1 / (1 + ValueRetentionScale * VP_IC_Val))`, bypassed to `1.000` when `IsThreatened == 1`, all cut paths are critical (`F_Crit == F_Paths`), or `F_Paths == 0`. |
| `SalientEvacuationQuota` | Final quota in `[0.000, 1.000]`: `clamp(D_Width * T_Neck * V_Ret, 0.0, 1.0)` (floored at `ThreatenedSourceQuotaFloor` if `IsThreatened == 1`, or `1.000` if `F_Crit >= 1`; snapped to `0.000` below `MinEvacuationQuotaThreshold` and zeroed when locked as an active upstream evacuation neck in Step 5C / Pass 2 `.raw_lock_loop`), quantized to `0..255` in `quota_q8`. |
| `NormAIPrio` | `NormalFrontAIPriority(P) = S(P) * D_front` (measured in divisions, formatted `%u.%u`), cached in `norm_prio_f32` (`g_pGraphTable + 0x58000`) by `Cave_FrontAI_ScaleReceiverShare` during `CFrontAI::MoveUnitsToFront` Loop B (`0x00684551`). |
| `AdjAIPrio` | `AdjustedPriority(P) = NormAIPrio * (1.0 - SalientEvacuationQuota)` (measured in divisions, formatted `%u.%u`), synced from `norm_prio_f32[P] * (255 - quota_q8[P]) / 255.0`. When `SalientEvacuationQuota == 1.000`, `AdjAIPrio == 0.0`. |
| `IsBottleneck` | `1` if one or more evacuating salient provinces (`SalientEvacuationQuota > 0`) depend on this province as a bottleneck (`AggNeckQuota > 0` after the Step 5E Active Evacuation Guard), `0` otherwise. |
| `AggNeckQuota` | Aggregated bottleneck quota `Q_agg` (`0.000..1.000`) computed across all upstream evacuating provinces referencing this bottleneck (including adjacent `IsThreatened == 1, quota_q8 == 0, FrStr > 0, Dist[S] < Dist[P]` holding shoulders via Step 5E `.s5ea_chk_thrt_nbs`) according to `[FrontAI] BottleneckQuotaAggregation` (`0 = MAX`, `1 = AVERAGE`, `2 = MIN`), stored in `neck_agg_q8` (`+0x42000`). Floored by the Threat-Sustaining Neck Floor (`.s5e_fin_threat_floor`) when `EnStr > 0.05` so active bottlenecks cover `EnStr / (max(0.05, NeckThreatMinRatio) * DefMult)` up to `NormAIPrio + BottleneckDefenseBoost`. Zeroed whenever `SalientEvacuationQuota > 0`. |
| `FinalAIPrio` | `AdjustedNeckPriority(B) = AdjAIPrio(B) + BottleneckDefenseBoost * AggNeckQuota(B)` (measured in divisions, formatted `%u.%u`): effective target garrison/front priority applied by Loop B (`0x00684551`/`0x0068470D`/`0x0068526A`), Loop A candidate boosting (`0x00684088`), and Loop A interior bottleneck hold (`0x00683C9D`). |
| `TargetStayDivs` | Stage 4 whole-division garrison target kept inside an evacuating province (`0` when `SalientEvacuationQuota == 1.000` or `AdjAIPrio < 1.0`; otherwise `round(AdjAIPrio)`), stored in `g_pGraphTable + 0xC0000 + prov * 4` (`+0`). |
| `StayingDivs` | Non-retreating friendly land divisions in the province not already STEM-locked (`[slot + 6] == 0`) or marching directly to `EvacDestNeck` (`+0xC0001`). |
| `EvacDivBudget` | Stage 4 excess divisions scheduled for withdrawal on the latest hourly evaluation (`max(0, StayingDivs - TargetStayDivs)`, `+0xC0002`), dispatched cleanly without exceeding the budget (`num_divs <= EvacDivBudget`; when `EvacDivBudget > 0` and no whole corps fits, `.uae_split_try` splits exact `EvacDivBudget` divisions out of an eligible non-combat corps). |
| `StatusFlags` | Phase 2 per-province status bitmask (`g_pGraphTable + 0xEC000 + prov`): `0` = normal, `+1` (`0x01`) = manually blacklisted from evacuation via `front.province_priorities` (`prio < 0.0` or `prio >= EvacuationBlacklistPriorityThreshold`), `+2` (`0x02`) = impassable supply lifeline (Stage 3), `+4` (`0x04`) = coastal port supply lifeline (Stage 3), `+8` (`0x08`) = `IsThreatened` cooldown hold active (Stage 5), `+16` (`0x10`) = evacuation re-entry cooldown hold active (Stage 5), `+32` (`0x20`) = country `stem_soft_mode = 1` active, `+64` (`0x40`) = country `stem_no_evac = 1` / `stem_evac_modifier = 1` ("Fight to the Death") active. |
| `EvacMult` | Effective evacuation quota multiplier applied to this province (`0.00` when blacklisted or in "Fight to the Death" mode; otherwise `country_evac_mult` from `local_flags = { stem_evac_modifier = N }` / `100.0`, default `1.00`, formatted `%u.%02u` from `g_pGraphTable + 0xFC000 + prov * 2`). |

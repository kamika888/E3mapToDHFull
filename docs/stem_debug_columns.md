# `stem_debug.csv` Column Reference

Semicolon-delimited (`;`) debug telemetry dumped to `stem_debug.csv` in the Darkest Hour root directory upon saving (manual save or autosave) when `EnableSTEM = 1` in `db/mod_settings.ini`.

| Column | Meaning |
|---|---|
| `CountryTag` | 3-letter tag of the evaluated AI country controlling the province (`UNK` if lookup fails). |
| `ProvID` | Numeric province ID (`1..8020`). |
| `ProvName` | Localized province name read from `[CProvince + 4]` (English name from `map/Map_3/province_names.csv` when running in English; `UNK` if null). |
| `Dist` | BFS hop distance (`0..65535`) from the nearest safe rear horizon / capital / depot (`0` = safe root). |
| `IsThreatened` | `1` if Pass 0 flagged the province as threatened (`+0x24000`), `0` otherwise. Set either when friendly defenders are losing badly in combat here (`CombatStrengthRatioThreshold = 1.5`, i.e., combat progress <= `0.40`, or avg division org < `10.0`), or when an active hostile moving army's immediate next hop (`[army + 0x27E] == 1`, `[army + 0x232]` list head) targets an unguarded friendly province. |
| `F_Paths` | Max-flow count of vertex-disjoint safe escape paths from this province to safe roots, capped at `SalientNeckWidthThreshold` (`3`). Reaching `3` immediately marks the province safe (`SalientEvacuationQuota = 0.000`). |
| `F_Exp` | Count of extracted minimum-cut bottleneck vertices (`1 <= F_Paths < W`) that have `IS_LAND_EXPOSED` (`prov_flags` bit `0x08`: borders a war enemy / hostile army, or borders an `IsThreatened == 1` province). If `F_Exp == 0` and `IsThreatened == 0`, the **Natural Geography Gate** zeroes the quota. |
| `F_Crit` | Subset of `F_Exp` cut vertices that are already `IsThreatened == 1` or have individual bottleneck threat `T(v) >= 1.0`. |
| `CutProv1`, `CutProv2` | First two province IDs on the residual max-flow minimum cut separating the province from the safe rear (`0` if safe, `F_Paths == 0`, or fewer cut vertices exist). |
| `EvacDestNeck` | Resolved evacuation destination neck province ID (`0` when not evacuating). |
| `FrStr` | Friendly non-retreating strength in division-equivalents at **reference vertex `v_ref`** (worst exposed cut vertex if any, else `CutProv1`, else the province itself when safe or `F_Paths == 0`). |
| `EnStr` | Weighted enemy strength threatening `v_ref` (`en_eff_str_f32`): sum of `ActiveEnemyAttackWeight` (`1.0`) for enemy divisions actively attacking or moving into `v_ref`, plus `IdleEnemyPresenceWeight` (`0.25`) * adjacent idle `raw_hostile_str`, plus `ThreatenedNeighborStrWeight` (`1.0`) propagated from adjacent `IsThreatened` friendly provinces via Pre-Pass B. |
| `InbStr` | Friendly non-retreating strength currently marching into `v_ref` (`[army + 0x27E] == 1` and immediate next hop `[army + 0x232]` head == `v_ref`), excluding units actively executing a STEM evacuation (`[slot + 6] != 0`). |
| `MinOrg` | Minimum average division organization (`0..254`, or `255` when not in defensive combat) of friendly defenders in `v_ref`. |
| `VP_IC_Val` | Strategic value of this province plus its friendly-controlled land neighbors: `sum(max(0, VP) + 0.5 * max(0, IC))`. |
| `D_Width` | Neck-width deficit in `[0.000, 1.000]`, `max(0, (W - (F_shelt + 0.5 * F_intact_exp)) / W)`, where `F_shelt = F_Paths - F_Exp` and `F_intact_exp = F_Exp - F_Crit` (`0.000` when gated safe; `1.000` when `F_Paths == 0`). |
| `T_Neck` | Bottleneck threat urgency clamped to `[NeckThreatMinFloor, NeckThreatMaxCap]` (`[0.00, 1.50]`) then scaled by `NeckThreatWeight` (`1.0`): worst cut vertex threat `T(v_max) * (1 + MultiExposedCutBonus * (F_Exp - 1))`, where `T(v)` ramps linearly from `0.0` at `NeckThreatMinRatio` (`1.0`) to `1.0` at `NeckThreatRatio` (`1.5`) — or `NeckThreatMaxCap` when unguarded with `EnStr > 0.05` — combined with `max` of low-org urgency against `NeckCollapsingOrgThreshold`. (`NeckThreatMinFloor` when gated safe; `NeckThreatMaxCap` when `F_Paths == 0`). |
| `V_Ret` | Value-retention multiplier clamped to `[ValueRetentionMinFloor, 1.000]`: `max(ValueRetentionMinFloor, 1 / (1 + ValueRetentionScale * VP_IC_Val))`, bypassed to `1.000` when `IsThreatened == 1`, all cut paths are critical (`F_Crit == F_Paths`), or `F_Paths == 0`. |
| `SalientEvacuationQuota` | Final quota in `[0.000, 1.000]`: `clamp(D_Width * T_Neck * V_Ret, 0.0, 1.0)` (floored at `ThreatenedSourceQuotaFloor` `0.85` if `IsThreatened == 1`, or `1.000` if `F_Crit >= 1`; snapped to `0.000` below `MinEvacuationQuotaThreshold` `0.05` and zeroed when locked as an active upstream evacuation neck in Step 5C / Pass 2), quantized to `0..255` in `quota_q8`. |
| `NormAIPrio` | `NormalFrontAIPriority(P) = S(P) * D_front` (measured in divisions, formatted `%u.%u`), cached in `norm_prio_f32` (`g_pGraphTable + 0x58000`) by `Cave_FrontAI_ScaleReceiverShare` during `CFrontAI::MoveUnitsToFront` Loop B (`0x00684551`). |
| `AdjAIPrio` | `AdjustedPriority(P) = NormAIPrio * (1.0 - SalientEvacuationQuota)` (measured in divisions, formatted `%u.%u`), synced from `norm_prio_f32[P] * (255 - quota_q8[P]) / 255.0`. When `SalientEvacuationQuota == 1.000`, `AdjAIPrio == 0.0`. |
| `IsBottleneck` | `1` if one or more evacuating salient provinces (`SalientEvacuationQuota > 0`) depend on this province as a bottleneck (`AggNeckQuota > 0` after the Step 5E Active Evacuation Guard), `0` otherwise. |
| `AggNeckQuota` | Aggregated bottleneck quota `Q_agg` (`0.000..1.000`) computed across all upstream evacuating provinces referencing this bottleneck according to `[FrontAI] BottleneckQuotaAggregation` (`0 = MAX`, `1 = AVERAGE`, `2 = MIN`), stored in `neck_agg_q8` (`+0x42000`). Zeroed whenever `SalientEvacuationQuota > 0`. |
| `FinalAIPrio` | `AdjustedNeckPriority(B) = AdjAIPrio(B) + BottleneckDefenseBoost * AggNeckQuota(B)` (measured in divisions, formatted `%u.%u`): effective target garrison/front priority applied by Loop B (`0x00684551`/`0x0068470D`/`0x0068526A`), Loop A candidate boosting (`0x00684088`), and Loop A interior bottleneck hold (`0x00683C9D`). |
| `TargetStayDivs` | Stage 4 whole-division garrison target kept inside an evacuating province (`0` when `SalientEvacuationQuota == 1.000` or `AdjAIPrio < 1.0`; otherwise `round(AdjAIPrio)`), stored in `g_pGraphTable + 0xC0000 + prov * 4` (`+0`). |
| `StayingDivs` | Non-retreating friendly land divisions in the province not already STEM-locked (`[slot + 6] == 0`) or marching directly to `EvacDestNeck` (`+0xC0001`). |
| `EvacDivBudget` | Stage 4 excess divisions scheduled for withdrawal on the latest hourly evaluation (`max(0, StayingDivs - TargetStayDivs)`, `+0xC0002`), dispatched cleanly without exceeding the budget (`num_divs <= EvacDivBudget`). |
